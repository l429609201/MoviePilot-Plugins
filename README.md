# MoviePilot 插件

面向 **MoviePilot V3（当前声明要求 ≥ 3.1.2）** 的媒体库与弹幕自动化插件。

## 安装

1. 在 MoviePilot 的插件市场设置中添加仓库地址：

   ```text
   https://github.com/l429609201/MoviePilot-Plugins
   ```

2. 刷新插件市场，选择所需插件并安装。
3. 根据插件需要配置 MoviePilot 媒体服务器、TMDB、AI 或外部服务连接。

当前 V3 插件索引均声明 `release: true`。正式发行采用每个插件独立的 GitHub Release：

- Tag：`插件ID_v版本号`，例如 `EmbyScraper_v3.0.0`
- 资产：`插件目录小写_v版本号.zip`，例如 `embyscraper_v3.0.0.zip`

**仅更新索引并不代表发行包已经发布。** 实际可安装的发行版本以 [Releases](https://github.com/l429609201/MoviePilot-Plugins/releases) 为准。

官方 MoviePilot 普通安装会优先使用 Release，下载失败时可能回退仓库文件列表；安装指定历史 Release 版本时不回退当前源码。本仓库不能仅通过索引强制禁止宿主回退。

## Emby刮削器

通过 Emby REST API 更新电影、电视剧、季与单集的元数据及图片，不直接编辑媒体目录中的 NFO。NFO 是否同步保存由 Emby 媒体库设置及写权限决定。

### 刮削参数

- 复用 MoviePilot 已配置的 Emby 服务与 TMDB 客户端，不额外维护同一套服务凭据。
- 显式选择服务器和媒体库；未选择范围时不自动处理全部媒体。
- 支持所选字段补缺或覆盖，默认尊重 Emby 元数据锁定。
- 可设置刮削语言、评分地区、图片语言优先级与尺寸、演员数量、演职员选择、匹配阈值和特别篇处理。
- 优先使用 TMDB 官方目标语言内容；可选择复用 MP AI 翻译简介、宣传语、单集标题及作品标题。
- `OriginalTitle`、外部 ID、日期、评分和人物结构数据不参与 AI 翻译。启用 AI 后相关文本将发送给 MP 配置的模型服务。
- 语言证据不足或翻译失败时跳过相关字段并提示，不以未确认的译文覆盖已有内容。

### 剧集组与任务

- 支持播出顺序、手动指定及保守自动识别剧集组，预览原始季集与目标排列。
- 保存绑定仅修改规则，不立即改写 Emby。
- 编号转换需明确开启并确认；首期仅执行同季容器已核验且目标位置未占用的转换。
- 跨季迁移、编号交换、目标冲突和不可靠映射会阻断，不移动物理文件。
- 支持定时分页扫描、整理入库触发、批量处理、取消和安全失败重试。
- 写入前备份，恢复前校验当前状态冲突；未知写入及重启中断不会自动重复执行。
- 备份上限为 100 条，达到上限后拒绝新增写入，不自动删除用户备份。

## 弹幕库自动导入

两种调用模式可在配置页选择：

- **全自动导入**：由弹幕库外部控制 API 搜索并决定数据源。
- **搜索 + MP AI 匹配**：先获取搜索候选，结合整理事件的媒体信息使用 MP AI 选择；AI 不可用或输出无效时执行纯代码匹配，不静默切换全自动模式。

指定分集使用分集查询与编辑导入，避免误导入整季。HTTP 202 仅表示远端接受任务；插件跟踪实际执行任务终态后才标记成功。明确冲突、歧义或结果不明的任务保留人工确认状态。

## 开发与 UI

后端按插件目录组织。Vue UI 源码在各插件本机开发目录 `plugins.v3/<插件>/vue/` 中，按当前维护策略由 Git 忽略；仓库及发行包只提供已编译的 `dist/assets/`。

拥有本地 Vue 工程时，可在该工程目录运行：

```bash
npm ci
npm run check:sfc
npm run build
```

构建产物使用 Vue 模块联邦，包含 `remoteEntry.js`、组件及全部引用的 JS/CSS，运行时复用 MoviePilot 的 Vue，不在宿主内编译 `.vue` 源文件。**仅克隆公开仓库不能重建 UI**，需要另行保有本地 Vue 开发工程及锁文件。


## 使用注意

- 首次在专用测试媒体上验证匹配、字段覆盖、图片及恢复行为，再启用批量自动处理。
- 图片按内容回读核验；Emby 重编码等版本差异可能导致保守判定未确认，需检查实际条目。
- API 写入与 NFO、在线刮削结果可能互相覆盖，应统一媒体库的元数据策略。
- 不应把 API 密钥、账户令牌或真实媒体库配置写入仓库、截图和日志。
- 操作记录、备份与可重建缓存应区分管理；缓存清理不能删除恢复所需的备份文件。
